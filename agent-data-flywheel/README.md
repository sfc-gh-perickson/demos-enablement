# AI Agent Data Flywheel

Strategic positioning deck making the case for Snowflake as the converged platform for AI agents that improve over time. Designed for CxO/VP-level conversations about where agent improvement data should live.

## Audience

Enterprise prospects evaluating AWS AgentCore, Azure AI Agent Service, or GCP Vertex Agent Builder alongside Snowflake Cortex Agents.

## Key Thesis

The data flywheel (business data + evaluation data + observability data → improvement) only works when all three data types converge in a single governed platform.
