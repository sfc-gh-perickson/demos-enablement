The Challenge

Every shipment that arrives at Springfield needs its packing slip data entered into the system before receiving can close. Today that's a manual process.

300+ slips a day, 27+ suppliers

Each supplier sends a different format — packing slips, bills of lading, shipment forms, warehouse acknowledgements. No two look alike. Someone has to read each one and key in PO numbers, part numbers, quantities, and carrier info.

4 hours of data entry, every day

That's half a shift spent transcribing from paper. On heavy receiving days it pushes past 5 hours, creating a backlog that delays PO reconciliation and inventory updates.

Errors propagate downstream

A wrong quantity or transposed part number on a packing slip becomes a discrepancy in the ERP, which someone else has to investigate. Manual entry error rates of 1-3% are typical.

The data stays on paper too long

Until someone finishes keying it in, the shipment data isn't in the system. Downstream processes — receiving confirmation, AP matching, inventory — are all waiting on that manual step.

Zero code changes per plant

The AI handles any supplier format. Adding a new plant means uploading their PDFs to the same stage. No model retraining, no template configuration, no per-supplier setup.

Shared infrastructure

One Snowflake database, one Streamlit app, one stored procedure. Each plant's data is isolated by file naming, but the pipeline and review UI are shared. Operational overhead doesn't scale with plant count.

Go/no-go at every gate

Each phase validates before the next begins. Month 1-2 proves accuracy. Month 3 proves the workflow. US Wave 1 proves it generalizes. Nothing scales until the previous step succeeds.

Structured data, ready to load

The pipeline outputs clean, normalized tables: one row per packing slip header, one row per line item. PO numbers, part numbers, quantities, supplier info — all in columns that map directly to ERP receiving record fields.

PO reconciliation before it hits the ERP

The pipeline automatically joins extracted shipments against purchase orders. Quantity mismatches, unknown parts, and missing POs are flagged before the data ever leaves Snowflake. The ERP only gets clean, validated records.

Multiple integration paths

Push to the ERP via Snowflake connectors, REST API, file export, or direct database integration. The approved packing slip data sits in standard Snowflake tables that any integration tool can read.

Audit trail included

Every extraction is logged: original PDF, OCR text, AI output, confidence score, reviewer name, corrections made, approval timestamp. Full traceability from scanned document to ERP record.

The Review Workflow

Staff verify what the AI flagged — not every single slip

See the actual document

Each slip is its own PDF file. The review app shows the original scanned document on the left and the extracted fields on the right. What you see is what you're reviewing — no page navigation, no guessing.

Edit anything inline

Every field is editable: PO number, supplier, dates, carrier, tracking number, addresses. Line items can be corrected, added, or deleted. Hit "Save Corrections" and it's done.

68% auto-approved in the POC

High-confidence extractions skip the queue entirely. Staff only review the slips where the AI is uncertain — low confidence scores, missing fields, or unusual formats. 5% are randomly spot-checked for quality.

Operational dashboard

Volume metrics, supplier breakdown, confidence distribution, field completeness rates, and error logs. Visibility into how the pipeline is performing without running SQL.

Next Steps

1. Connect PO data from the ERP

The POC uses mock purchase orders. Connecting the real PO feed enables live reconciliation — flagging quantity mismatches and unknown parts before they become receiving discrepancies.

2. Pilot alongside manual entry

Run the pipeline on live daily volume for two weeks alongside the existing process. Compare extraction accuracy, measure review time, and tune the confidence thresholds on real data.

3. Define the ERP integration

Map the extracted fields to the ERP's receiving record schema. Set up the push — whether that's a Snowflake connector, file export, or API call — so approved slips flow directly into the system of record.

4. Roll out to additional facilities

The pipeline handles any supplier format without code changes. Adding a new plant is uploading their PDFs to the same stage. The AI, review app, and ERP integration all work the same way.
