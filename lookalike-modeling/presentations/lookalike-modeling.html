Feature Store as Governed Catalog

The agent browses registered feature views — not raw tables. Governed definitions prevent drift.

Feature ViewFeaturesDomain

Cortex Agent Skills

A SKILL.md file on a stage — the agent discovers and executes it automatically.

What is a Skill?

name: lookalike_modeler

description: Build a lookalike audience model...

instructions: Multi-step workflow

scripts: profile_and_select.py, train_and_score.py

Why Skills?

Portable — reuse across agents

Versionable — store on stage or Git

Scriptable — Python for heavy computation

Discoverable — agent auto-selects when relevant

The Lookalike Skill Workflow

Step 1-2

Profile the Seed

Run profile_and_select.py to understand how the seed differs from the universe across all Feature Store views.

Step 3

Select Features

LLM reasons about the profile, proposes features. Statistical validation (MI + correlation) prunes weak signals.

Step 4-5

Train + Report

XGBoost via Feature Store. Score universe, compute lift, register model, report results in plain language.

The agent makes different feature selections per seed — not a one-size-fits-all template.

Intelligent Feature Selection

LLM reasoning + statistical validation = governed intelligence

LLM Reasoning

"This seed over-indexes on homeowners aged 35-44 with high H&G spend. I should prioritize: HOMEOWNER, PCT_HOME_GARDEN, AGE, MAIL_RESPONSE_RATE..."

Proposes 15-25 candidates

Statistical Validation

For each proposed feature, compute:

Mutual Information (MI ≥ 0.01)

Point-biserial correlation (|r| ≥ 0.05)

Keeps 8-20 validated features

DS Monitoring Toolkit

Cumulative Gains

How many seed members does each decile capture? Top decile should capture 20-30% with 10% of the universe.

Lift Analysis

Lift per decile vs. random baseline. Decile 1 should exceed 2x. Below 1.5x = flag for review.

Feature Selection Audit

Do the agent's top features align with domain knowledge? "H&G model should be driven by HOMEOWNER."

PSI Drift Detection

Population Stability Index tracks scoring distribution shift. PSI > 0.2 triggers retraining.

Quality Gates

Automated pass/fail before any model reaches production.

CheckThresholdRationale
AUC≥ 0.65Minimum discrimination ability
Lift @ Decile 1≥ 2.0xTop decile must outperform random
PSI< 0.2Scoring distribution is stable
Feature Count8-30Guards against under/over-fitting
Feature CoherenceAll MI > 0.01No hallucinated feature names

Models passing all checks: APPROVED
Models failing any check: NEEDS_REVIEW — escalated to DS team
